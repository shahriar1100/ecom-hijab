# Demo image provenance

These are AI-generated, replaceable placeholder photographs created with the built-in image-generation tool. They are not client product photographs. The reference screenshots themselves are not shipped or rendered by this app. The hero used the supplied desktop design as a visual reference; every other image was generated separately. Final files are in `public/images/` as optimized WebP assets.
